## 二、核心功能详解

### 1. 视频采集：按关键词或ID，一键批量获取

无论是搜"珍珠""牛仔裤"还是"电动车"，输入关键词就能批量采集视频列表，显示播放量、点赞数、发布时间等关键数据。也可以直接输入视频ID精准采集。

**适用场景**：竞品监控、爆款素材收集、行业趋势分析

### 2. 评论采集+过滤：精准筛选高价值评论

这个功能非常实用。采集评论后，可以按关键词过滤（比如只采集含"求链接""怎么买"的评论），也可以按点赞数筛选——高赞评论往往代表用户真实痛点。

**适用场景**：用户需求调研、意向客户挖掘、口碑分析

### 3. 用户采集+作者信息导出：精准锁定目标账号

按关键词（如"老王"）、粉丝量区间、获赞量筛选目标用户，采集后可直接导出账号信息：昵称、抖音ID、IP属地、粉丝数、获赞数、作品数、个性签名……一目了然。

**适用场景**：达人筛选、竞品账号分析、潜在合作方挖掘

### 4. 作者作品采集：一个账号的所有视频，一键拿下

找到对标的优质作者，不用一个个翻主页，一键采集该账号全部作品，批量下载或导出。

**适用场景**：内容拆解、素材库搭建、跟拍爆款

### 5. 已采评+一键评论+一键关注+一键回复：私域引流闭环

- **已采评**：记录已采集过的评论，避免重复工作
- **一键评论**：批量给采集到的视频自动评论
- **一键关注**：批量关注目标用户
- **一键回复**：批量回复评论区的用户留言
- **私信发送**：抖音平台支持批量私信（注意合规使用）

这套组合拳下来，从"找用户"到"触达用户"到"引流私域"，全流程自动化。
